ASCII: ~ → ¬, & oder /\ → ∧, \/ → ∨, -> → →, <-> → ↔. Klammerregeln wie im LPL-Buch (Abschnitt 3.5): ¬ bindet nur an die unmittelbar folgende Formel, die binären Junktoren haben keine Rangfolge untereinander. A ∧ B ∧ C und A ∨ B ∨ C sind erlaubt, A ∨ B ∧ C dagegen nicht. Äußerste Klammern dürfen entfallen; [ und { gelten als Klammern.

Bedienung: Zelle anklicken schaltet weiter (leer → W → F → leer). Tastatur: w für wahr, f für falsch, Entf löscht, Pfeiltasten bewegen. Die Spalte unter dem Hauptjunktor jeder Formel ist hervorgehoben.
